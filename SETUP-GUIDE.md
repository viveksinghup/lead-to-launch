# Lead → Launch — Setup Guide

Find local-business clients, audit their websites, rank them, generate a site-builder prompt, and draft outreach — in one dashboard.

**5 phases:** Scrape Google Maps → Audit (Claude) → Rank (Claude) → Build site prompt (Claude) → Outreach (Claude, Hinglish/English + day-3 follow-up).

---

## How it works — the dashboard runs on Claude Code

The dashboard is the UI. The **thinking** for Phases 2–5 (audit, ranking, website prompt, outreach) runs on **Claude Code on your own machine, under your Claude subscription — no API key.** When you click a button, the app calls your local `claude` and shows the result.

- **Phase 1 (Scrape)** — pulls leads from **Apify** (or the built-in demo data). Does **not** need Claude Code.
- **Phases 2–5 (Audit → Rank → Build → Outreach)** — **require Claude Code installed and logged in.** This is where the real analysis, ranking, website prompt, and outreach copy are generated.

A top-right badge shows **"Claude Code connected"** (green) or **"not found"** (red). If it's not found, Phases 2–5 show an "Install Claude Code" panel instead of running.

> Same pipeline also runs as a pure chat skill in `.claude/skills/` — open the folder in Claude Code and say "run /lead-to-launch". No browser needed.

## 2. Install & run

**Mac:**
1. Unzip the folder anywhere (e.g. Desktop).
2. Double-click `Launch.command`.
   - If macOS blocks it: right-click → **Open** → **Open** (one-time).
3. Browser opens at `http://localhost:3000` automatically.

**Windows:**
1. Unzip the folder.
2. Double-click `Launch.bat`.
3. Open `http://localhost:3000` in your browser.

**Manual (any OS):**
```bash
cd app
npm install
npm run dev
# open http://localhost:3000
```

First run installs dependencies (1–2 min). To stop: press `Ctrl + C` in the terminal window, or close it.

---

## 3. Turn on Claude Code (required for Phases 2–5)

The audit, ranking, website prompt, and outreach are generated by **Claude Code running locally under your subscription** — no API key.

1. Install Claude Code: [claude.com/claude-code](https://claude.com/claude-code).
2. Open a terminal, run `claude` once, and sign in with your Claude account.
3. Start (or restart) the dashboard. The top-right badge should read **"Claude Code connected"** (green).

If the badge says **"not found"**, Phases 2–5 will show an "Install Claude Code" panel. Phase 1 (scraping) still works without it.

> Each AI phase takes ~20–60 seconds (real inference on your machine) and shows a "Claude is working" state while it runs. That's normal.

## 4. Optional: live Google Maps scraping (Apify)

Without this, Phase 1 uses the built-in demo dataset. To scrape real businesses:

```bash
cd app
cp .env.local.example .env.local
```
(Windows: copy `.env.local.example`, rename the copy to `.env.local`.)

1. Sign up free at [apify.com](https://apify.com) (no card needed).
2. **Settings → API & Integrations → API tokens** → copy your token (`apify_api_...`).
3. Paste into `app/.env.local`:
   ```
   APIFY_TOKEN=apify_api_xxxxxxxxxxxx
   ```
4. Leave `APIFY_ACTOR` as is (Google Maps Scraper — no install needed). Restart the server.

Free tier = $5/month credit ≈ 500–700 leads. A 12–25 lead run costs a few cents.

## 5. Using the tool

1. **Phase 1 — Scrape:** enter niche ("Salon"), city ("Andheri, Mumbai"), count (12–25). Hit scrape. (Apify or demo data — no Claude needed.)
2. **Phase 2 — Audit:** select leads → "Run audit with Claude". Claude analyzes each business's gaps, biggest opportunity, and estimated lost ₹/month (~30–60s).
3. **Phase 3 — Rank:** "Rank prospects with Claude" — scores each lead 0-100 with a one-line reason. Pick your best prospect.
4. **Phase 4 — Build:** pick a platform → "Generate with Claude" → get a full builder prompt + pitch points. Copy into Lovable / Bolt / Claude Code, get a demo site, deploy free (Vercel/Netlify), copy the link.
5. **Phase 5 — Outreach:** pick channel + Hinglish/English → "Draft with Claude" → a first message + day-3 follow-up. Before sending, replace:
   - `[your-demo-link]` → your deployed demo URL
   - `[Your Name]` → your name

## First launch: what's normal

- After `npm run dev`, wait for the line **`✓ Ready`** before opening the browser.
- The **first** page load compiles the map/chart libraries once — it can take **10–30 seconds** (the tab will spin, then the dashboard appears). This is normal; every load after is instant.
- If you opened the browser too early and got **"localhost refused to connect"**, just refresh the tab (`Cmd/Ctrl + Shift + R`) once `✓ Ready` shows. `Launch.command` waits for the server automatically, so use it to avoid this.

## Troubleshooting

| Problem | Fix |
|---|---|
| `node: command not found` | Install Node.js from nodejs.org, restart terminal |
| Badge says "Claude Code not found" / Phases 2–5 won't run | Install Claude Code (claude.com/claude-code), run `claude` once in a terminal and sign in, then click Retry |
| A Claude phase errors with "usage credits" or "log in" | Run `claude` in a terminal to confirm you're signed in and your plan is active, then retry |
| Claude phase is slow (20–60s) | Normal — it's running real inference locally. The "Claude is working" state shows while it runs |
| Browser says "localhost refused to connect" | Server wasn't ready yet — wait for `✓ Ready`, then refresh. Or open `http://127.0.0.1:3000` |
| Server starts but every page hangs forever | You have a stray `package.json` / `package-lock.json` / `node_modules` in your **home folder** (`~/`). Next then tries to scan your whole home dir. Move them aside: `mv ~/package.json ~/package.json.bak` (same for `package-lock.json` and `node_modules`) |
| `npm run dev` hangs with no output at all | The project folder path contains a space and Turbopack stalls. Move the folder to a space-free path (e.g. `~/lead-to-launch`), or run `npm run dev:webpack` |
| Port 3000 busy | Another copy is already running — try `http://localhost:3000` first. Else `PORT=3001 npm run dev` (Mac) / `set PORT=3001 && npm run dev` (Windows) |
| Mac blocks Launch.command | Right-click → Open → Open. Or run `chmod +x Launch.command` in Terminal |
| Scrape returns demo data with token set | Key must be in `app/.env.local` (not the example file); restart server |
| Apify error / empty results | Check token, check credit balance at console.apify.com |
